# Netflix Clone

This is a simple Netflix clone built with **React**. The project replicates the Netflix UI, providing a movie browsing experience, but without backend functionality. It is purely a front-end project.

---

## Features

- **Movie Browsing**: Browse through a static collection of movies displayed in rows.
- **User Interface**: A user interface similar to Netflix with a navigation bar and movie categories.

---

## Technologies Used

- **React.js**: A JavaScript library for building user interfaces.
- **CSS**: For custom styling to replicate the Netflix look and feel.
- **React Hooks**: To manage the state in the app.

---

## Installation
1. ** Install dependencies **
    cd netflix-clone
    npm install

3. ** Run the app **
    npm start
    
    Visit http://localhost:3000 to view the app in your browser.
